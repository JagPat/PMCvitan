HOW TO RUN IT
One stage open at a time, reproduce-first inside each
Each stage opens only when the previous one has cleared exact-head Codex review, so a later unit is never verified against a moving base. Within a stage, units are independent and can run in parallel — except Wave 0, where F-1c validates F-1a and F-1b and must follow both. Not yet design-ready: Wave 3 until the CommercialScreen split is decided, Wave 4 until worker authentication and device binding are settled, and Wave 5 acceptance until weekly-report export and architect rejection authority are resolved. Only the persona acceptance sessions close the gate, and none of this substitutes for them.
